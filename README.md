# Sentence Studio — downloads

Desktop apps for the **Sentence Studio — AI Rephrase** Chrome extension. Select text in Microsoft Teams or another app, press the shortcut, and choose from three rewrites: **Natural and clear**, **Professional** and **Short and direct**.

## Windows (preview)

**[Download Sentence Studio for Windows 0.1.1](https://github.com/sentence-studio/releases/releases/download/windows-v0.1.1/SentenceStudio-Windows-0.1.1.zip)**

1. Install the Sentence Studio extension in Chrome, choose ChatGPT or Gemini in its popup, and connect.
2. **Unblock the ZIP before extracting it.** Right-click the downloaded ZIP → **Properties** → tick **Unblock** at the bottom of the General tab → **OK**. This tells Windows you trust the download and avoids most security warnings. (If there's no Unblock box, Windows hasn't blocked it and you can skip this step.)
3. Extract the ZIP fully.
4. In the extension popup, open **Extension ID for installation** and copy the ID.
5. Double-click **Install.cmd** and paste the ID. No administrator access is needed.
6. Click **Connect Windows app** in the extension popup.
7. Select text in any app and press **Ctrl+Alt+R**.

Requirements: Windows 10 or 11 with .NET Framework 4.8, Chrome kept running, and Sentence Studio extension 0.4.0 or later connected to an AI provider: an eligible **ChatGPT Plus or Pro** account, or your own **Gemini API key** from Google AI Studio. The Windows app uses whichever provider you choose in the extension popup.

This is an unsigned preview. If you skipped the Unblock step and Windows SmartScreen warns you, choose **More info → Run anyway**, but only for files downloaded from this page. On Windows 11 with **Smart App Control** turned on, unsigned apps may be blocked entirely until a signed version is available. Full instructions are in the README inside the ZIP.
