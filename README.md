# Sentence Studio — downloads

Desktop apps for the **Sentence Studio — AI Rephrase** Chrome extension. Select text in Microsoft Teams or another app, press the shortcut, and choose from three rewrites: **Natural and clear**, **Professional** and **Short and direct**.

## Windows (preview)

**[Download Sentence Studio for Windows 0.1.1](https://github.com/sentence-studio/releases/releases/download/windows-v0.1.1/SentenceStudio-Windows-0.1.1.zip)**

1. Install the Sentence Studio extension in Chrome and sign in.
2. Extract the ZIP fully.
3. In the extension popup, open **Extension ID for installation** and copy the ID.
4. Double-click **Install.cmd** and paste the ID. No administrator access is needed.
5. Click **Connect Windows app** in the extension popup.
6. Select text in any app and press **Ctrl+Alt+R**.

Requirements: Windows 10 or 11 with .NET Framework 4.8, Chrome kept running, and an eligible ChatGPT Plus or Pro account. The Windows app currently supports the ChatGPT provider.

This is an unsigned preview. If Windows SmartScreen warns you, choose **More info → Run anyway** only for files downloaded from this page. Full instructions are in the README inside the ZIP.
